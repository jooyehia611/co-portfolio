# مميزات مشروع تعمير | Tameer Project Features

> قائمة مميزات الـBackend الحالية، مرتبة كمجموعات تناسب حقول «المميزات» في الصورة: لكل مجموعة عنوان بالعربية والإنجليزية، ولكل نقطة نص باللغتين. يمكن نقل كل مجموعة ونقاطها مباشرة إلى النموذج.

## 1. إدارة الشركات | Company Management

- **العربية:** إنشاء الشركات وعرض تفاصيلها وتعديلها وحذفها.  
  **English:** Create, view, update, and delete companies.
- **العربية:** تصفية قائمة الشركات والبحث فيها وعرض إحصاءاتها وتصدير بياناتها.  
  **English:** Filter and search companies, view their statistics, and export their data.
- **العربية:** إدارة معلومات العميل وبيانات التواصل والبريد المخصص للمشتريات والمكتب الخلفي.  
  **English:** Manage client information, contact details, and procurement and back-office email addresses.
- **العربية:** ضبط إعدادات الإشعارات والأمان لكل شركة.  
  **English:** Configure notification and security settings for each company.

## 2. إدارة المواقع | Site Management

- **العربية:** إنشاء المواقع وعرضها وتعديلها وحذفها وتعطيلها.  
  **English:** Create, view, update, delete, and deactivate sites.
- **العربية:** ربط المواقع بالشركات وتعيين مدير لكل موقع.  
  **English:** Link sites to companies and assign a manager to each site.
- **العربية:** حفظ بيانات الموقع وساعات عمله ومعلوماته الجغرافية.  
  **English:** Store site details, working hours, and geographic information.
- **العربية:** تحديد الموقع الحالي للمستخدم وحصر البيانات بالمواقع المسموح له الوصول إليها.  
  **English:** Select a user's current site and scope data to sites they can access.
- **العربية:** تنزيل قالب المواقع واستيرادها جماعيًا وتصدير بياناتها، بما في ذلك تصدير شامل لبيانات المواقع.  
  **English:** Download a site template, bulk import sites, and export site data, including a full site data export.

## 3. هيكل المواقع والوحدات | Location Hierarchy

- **العربية:** إدارة المناطق والمباني والأدوار والوحدات داخل المواقع.  
  **English:** Manage zones, buildings, floors, and units within sites.
- **العربية:** استعراض أدوار ووحدات المبنى ووحدات كل دور.  
  **English:** Browse a building's floors and units and the units on each floor.
- **العربية:** استيراد المباني والأدوار والوحدات من قوالب جاهزة.  
  **English:** Import buildings, floors, and units using downloadable templates.
- **العربية:** التحقق من اتساق الموقع والمبنى والدور والوحدة عند تسجيل أوامر العمل.  
  **English:** Validate the site, building, floor, and unit hierarchy when creating work orders.

## 4. المستخدمون والفرق | Users and Teams

- **العربية:** إنشاء المستخدمين وعرض ملفاتهم وتعديل بياناتهم وحذفهم.  
  **English:** Create users, view their profiles, update their details, and delete them.
- **العربية:** ربط المستخدمين بموقع واحد أو أكثر وبالأقسام المناسبة وإزالة ارتباطهم بموقع.  
  **English:** Assign users to one or more sites and departments, and remove site assignments.
- **العربية:** تفعيل المستخدمين أو إيقافهم، مع إمكانية التفعيل الجماعي.  
  **English:** Activate or suspend users, including bulk activation.
- **العربية:** استعراض الفنيين وإحصاءات المستخدمين وأداء أوامر العمل المرتبطة بهم.  
  **English:** List technicians and view user statistics and related work order performance.
- **العربية:** إدارة الأقسام وتوزيع المستخدمين عليها.  
  **English:** Manage departments and assign users to them.

## 5. الحسابات والأمان | Accounts and Security

- **العربية:** تسجيل حساب جديد وتسجيل الدخول والخروج باستخدام جلسات API.  
  **English:** Register accounts and sign in and out through API sessions.
- **العربية:** عرض الملف الشخصي وتعديله وتغيير كلمة المرور وحذف الحساب.  
  **English:** View and update profiles, change passwords, and delete accounts.
- **العربية:** استعادة كلمة المرور باستخدام رمز تحقق يُرسل بالبريد الإلكتروني.  
  **English:** Reset forgotten passwords using an email verification code.
- **العربية:** إرسال رمز التحقق بخطوتين والتحقق منه، مع إعداد لإلزام الشركة به.  
  **English:** Send and verify two-factor authentication codes, with a company setting to require them.
- **العربية:** عرض الحالة الأمنية للحساب وإلغاء الجلسات المسجلة.  
  **English:** View account security status and revoke active sessions.
- **العربية:** التحكم في الصلاحيات حسب الدور، وعرض صلاحيات الأدوار وتحديثها.  
  **English:** Control access by role, view role permissions, and update permission assignments.

## 6. الأصول وتصنيفاتها | Assets and Categories

- **العربية:** تسجيل الأصول وعرضها وتعديلها وحذفها وتصفيتها حسب الموقع والحالة والتصنيف.  
  **English:** Register, view, update, delete, and filter assets by site, status, and category.
- **العربية:** إدارة تصنيفات الأصول الهرمية والبحث ضمن التصنيفات الفرعية.  
  **English:** Manage hierarchical asset categories and search through child categories.
- **العربية:** توليد رقم تسلسلي للأصل وربطه بالموقع والتصنيف.  
  **English:** Generate asset serial numbers associated with their site and category.
- **العربية:** إنشاء رمز QR للأصل وتنزيله ومسحه لعرض بيانات الأصل وجدول صيانته.  
  **English:** Generate and download asset QR codes, and scan them to view asset details and maintenance schedules.
- **العربية:** إظهار أمر العمل المفتوح المسند للفني على الأصل عند مسح رمزه.  
  **English:** Show the scanning technician's assigned open work order for the asset.
- **العربية:** عرض خطط الصيانة الوقائية المرتبطة بالأصل وإحصاءات الأصول.  
  **English:** View an asset's related preventive maintenance plans and asset statistics.
- **العربية:** رفع صور وملفات الأصول بصورة فردية أو جماعية.  
  **English:** Upload asset images and files individually or in bulk.
- **العربية:** تنزيل قالب الأصول واستيرادها جماعيًا وتصدير بياناتها.  
  **English:** Download an asset template, bulk import assets, and export asset data.

## 7. خطط الصيانة الوقائية | Preventive Maintenance Plans

- **العربية:** إنشاء خطط صيانة وقائية وعرضها وتعديلها وحذفها وتجديدها.  
  **English:** Create, view, update, delete, and renew preventive maintenance plans.
- **العربية:** تحديد دورية الخطة اليومية أو الأسبوعية أو الشهرية أو الربع سنوية أو السنوية.  
  **English:** Set daily, weekly, monthly, quarterly, or yearly plan frequencies.
- **العربية:** تحديد تاريخ البداية والاستحقاق التالي والمدة التقديرية ومهلة الإسناد.  
  **English:** Set start dates, next due dates, estimated durations, and assignment windows.
- **العربية:** ربط الخطة بأصول وقوائم فحص متعددة وعرض الفنيين المناسبين لها.  
  **English:** Link plans to multiple assets and checklists and list suitable technicians.
- **العربية:** عرض إحصاءات الخطط وتنزيل قالبها واستيرادها وتصديرها.  
  **English:** View plan statistics, download a template, and import or export plans.
- **العربية:** إنشاء أوامر صيانة وقائية تلقائيًا من الخطط المستحقة عبر مهمة يومية مجدولة.  
  **English:** Automatically generate preventive work orders from due plans through a daily scheduled job.

## 8. قوائم الفحص ومهام الصيانة | Checklists and Maintenance Tasks

- **العربية:** إنشاء قوائم الفحص وعرضها وتعديلها وحذفها وربطها بالأصول وخطط الصيانة.  
  **English:** Create, view, update, and delete checklists linked to assets and maintenance plans.
- **العربية:** تنظيم مهام القائمة داخل مجموعات قابلة للإدارة والترتيب.  
  **English:** Organize checklist tasks into manageable, ordered groups.
- **العربية:** إنشاء مهام الصيانة وتعديلها وحذفها وتحديد تفاصيلها.  
  **English:** Create, update, and delete maintenance tasks and define their details.
- **العربية:** عرض إحصاءات قوائم الفحص وتصفية الأصول المناسبة لها.  
  **English:** View checklist statistics and filter eligible assets.
- **العربية:** تنزيل قوالب قوائم الفحص ومهام الصيانة واستيرادها، مع تصدير قوائم الفحص.  
  **English:** Download and import checklist and maintenance task templates, and export checklists.

## 9. أوامر الصيانة الوقائية المفتوحة | Open Preventive Work Orders

- **العربية:** عرض أوامر الصيانة الوقائية المفتوحة وتفاصيل الخطة والأصل والمهام المرتبطة بها.  
  **English:** View open preventive work orders with their related plan, asset, and task details.
- **العربية:** تصفية الأوامر حسب الحالة والدورية والتاريخ والموقع وفئة الخدمة وقطع الغيار، مع البحث النصي.  
  **English:** Filter orders by status, frequency, date, location, service class, and spare parts, with text search.
- **العربية:** إسناد أمر وقائي إلى فني وتحديد موعد انتهاء الإسناد.  
  **English:** Assign a preventive work order to a technician with an assignment deadline.
- **العربية:** إسناد أو حذف عدة أوامر وقائية دفعة واحدة وفق الصلاحيات.  
  **English:** Assign or delete multiple preventive work orders in one authorized action.
- **العربية:** إيقاف أمر الصيانة الوقائية مؤقتًا مع السبب والملاحظات، ثم استئناف تنفيذه.  
  **English:** Put a preventive work order on hold with a reason and remarks, then resume it.
- **العربية:** إكمال الأمر بعد إنجاز مهام الفحص وإرفاق صورة، مع حفظ الملاحظات.  
  **English:** Complete the order after checklist tasks are done and a photo is attached, with optional notes.
- **العربية:** عرض إحصاءات الأوامر الوقائية وتصديرها.  
  **English:** View preventive work order statistics and export their data.

## 10. أوامر الصيانة التصحيحية | Corrective Work Orders

- **العربية:** إنشاء طلب صيانة تصحيحية مرتبط بالموقع والمكان والقسم والأصل ونوع الخدمة والأولوية.  
  **English:** Create corrective requests linked to a site, location, department, asset, service type, and priority.
- **العربية:** إرفاق الصور والوصف ومصدر الطلب الخارجي عند تسجيل الطلب.  
  **English:** Attach photos and descriptions and record an external request source when creating a request.
- **العربية:** عرض الطلبات والبحث فيها وتصفيتها وعرض تفاصيلها وتعديلها وحذفها.  
  **English:** List, search, filter, view, update, and delete corrective requests.
- **العربية:** إسناد الطلب إلى فني وإعادة إسناده وتسجيل سجل الإسناد وتغيرات الحالة.  
  **English:** Assign and reassign requests to technicians and record assignment and status history.
- **العربية:** إدارة مراحل الاستجابة وبدء العمل والإيقاف المؤقت والاستئناف والإكمال والمراجعة والإغلاق.  
  **English:** Manage response, start, hold, resume, completion, review, and closure stages.
- **العربية:** إعادة الطلب إلى الفني نفسه مع ملاحظات عند الحاجة إلى استكمال العمل.  
  **English:** Return a request to the same technician with remarks when more work is needed.
- **العربية:** عرض إحصاءات الطلبات التصحيحية والفنيين المتاحين للإسناد.  
  **English:** View corrective request statistics and technicians available for assignment.

## 11. اتفاقيات مستوى الخدمة | Service Level Agreements

- **العربية:** إعداد مدد الاستجابة والحل حسب الموقع ونوع الخدمة والأولوية.  
  **English:** Configure response and resolution targets by site, service type, and priority.
- **العربية:** احتساب مواعيد الاستجابة والحل عند إنشاء طلب الصيانة التصحيحية مع مراعاة ساعات عمل الموقع.  
  **English:** Calculate response and resolution deadlines when corrective requests are created, using site working hours.
- **العربية:** إيقاف احتساب مدة SLA أثناء تعليق الطلب وتمديد موعد الاستحقاق عند استئنافه.  
  **English:** Pause SLA time while a request is on hold and extend deadlines when work resumes.
- **العربية:** إظهار زمن العمل الفعلي والوقت المجمّد ومدى الالتزام بمواعيد الاستجابة والحل.  
  **English:** Show active work time, frozen time, and response and resolution SLA performance.
- **العربية:** استخدام نتائج SLA في اللوحات والتقارير وإحصاءات المواقع والفنيين.  
  **English:** Use SLA results in dashboards, reports, and site and technician statistics.

  **English:** Add, update, and remove spare parts used on a work order and link them to its asset.
- **العربية:** إنشاء طلبات قطع غيار للأوامر التصحيحية وعرضها.  
  **English:** Create and view spare parts requests for corrective work orders.
- **العربية:** حفظ صور العمل والملاحظات وسجل الحالة أثناء تنفيذ الأوامر.  
  **English:** Save work photos, notes, and status history during order execution.
